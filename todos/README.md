# Local TODO Workspace

Purpose: keep in-progress and next-step items locally so new sessions can continue seamlessly.

Files:
- `active.md`: current prioritized backlog and status.
- `handoff.md`: concise context for next session (what changed, what is blocked, what to do first).
- `done.md`: local log of completed milestones not yet reflected elsewhere.

Usage rules:
1. Update `active.md` when adding/changing scope.
2. Update `handoff.md` at end of each work session.
3. Move finished items from `active.md` to `done.md`.
4. Promote durable decisions into tracked OpenSpec artifacts before merge.
